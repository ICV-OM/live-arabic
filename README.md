# عِشها بالعربية | Live Arabic

لعبة سياحية تعليمية ثلاثية الأبعاد تعمل في المتصفح على الهاتف والحاسوب: يسافر اللاعب بين محافظات سلطنة عُمان وولاياتها، يعيش مع عائلة عُمانية، ويتعلّم العربية بالمحادثة.

A 3D educational travel game that runs in the browser: explore the governorates and wilayats of Oman, stay with an Omani family, and learn Arabic through conversation.

## التشغيل

افتح `index.html` من خادم ويب (مثل GitHub Pages). التسجيلات الصوتية في مجلد `audio`.

- الهاتف: الوضع الأفقي، عصا التحكم أسفل اليمين، والسحب لتدوير الكاميرا.
- الحاسوب: مفاتيح WASD للحركة، Shift للجري، E للتحدث، والسحب بالفأرة للكاميرا.

## المحتوى

- 11 محافظة و63 ولاية بخمس بيئات: جبال وواحات، ساحل، أخوار مسندم، صحراء، وخريف ظفار.
- ثلاث مهمات في كل ولاية: التعارف مع العائلة، الضيافة العُمانية، والشراء من السوق.
- جواز المستكشف: الأختام والمهمات والمفردات، مع حفظ التقدّم في المتصفح.

## التقنية

ملف HTML واحد يستخدم Three.js r128 من cdnjs. المجسمات والخامات مولّدة بالكود، والأصوات مسجّلة عبر ElevenLabs.
